
# Data Science Environment Setup

## Project Overview
This project demonstrates the basic setup of a
Data Science environment using Anaconda,
Jupyter Notebook, Python, and Pandas.

## Objectives
- Understand Anaconda and Jupyter Notebook.
- Import the Pandas library.
- Load CSV datasets.
- Display the first five rows.
- Generate descriptive statistics.

## Technologies Used
- Python
- Anaconda
- Jupyter Notebook
- Pandas

## Project Structure
Data_Science_Environment_Setup/
- dataset/
- notebooks/
- README.md

## Implementation
1. Created a Jupyter Notebook.
2. Imported Pandas.
3. Loaded the CSV dataset.
4. Displayed records using head().
5. Generated statistics using describe().

## How to Run
1. Install Anaconda.
2. Install Pandas.
3. Open Jupyter Notebook.
4. Open data_analysis.ipynb.
5. Execute all cells.

## Result
Successfully loaded a CSV dataset,
displayed the first five records, and
generated descriptive statistical summaries.
